# Site da Findez Agência

Site estático de uma página para findezagencia.com.br, publicado pelo GitHub Pages.

## Arquivos
- index.html — página principal
- politica-de-privacidade.html — política de privacidade
- 404.html — página de erro
- robots.txt, sitemap.xml, llms.txt — arquivos para buscadores e IAs
- CNAME — domínio do GitHub Pages (findezagencia.com.br)
- fonts/ — fontes hospedadas no próprio site
- imagens da marca: logo-emblema.webp (e .png para o Google), logo-findez.webp, banner-findez.webp, og-image.jpg, apple-touch-icon.png, favicon.svg (os .jpg do banner e da logo ficam como reserva)
- Fotos ilustrativas carregadas do Unsplash (licença gratuita do Unsplash)

## Publicar (GitHub, pelo navegador)
1. Abra o repositório onde o site atual da Findez está publicado.
2. Add file → Upload files → arraste todos os arquivos e a pasta fonts (substituindo os antigos) → Commit changes.
3. Settings → Pages: confira se o domínio é findezagencia.com.br e se "Enforce HTTPS" está marcado.
4. Aguarde 1–2 minutos e abra o site no celular para conferir.

## Depois de publicar
- Testar todos os botões de WhatsApp e os links de Instagram e e-mail.
- Google Search Console: enviar https://findezagencia.com.br/sitemap.xml
- Validar os dados estruturados em https://search.google.com/test/rich-results
